# White Dove Cleaning

A custom, SEO-focused website built for White Dove Cleaning, a residential cleaning company serving Spokane, Washington, Coeur d’Alene, Idaho, and the surrounding region.

The project replaced the client’s previous GoDaddy website with a clean, lightweight custom build designed around search visibility, local service architecture, site performance, and lead generation.

## Project Overview

The primary goal of this rebuild was to create a faster, more scalable website with stronger technical and on-page SEO foundations.

Rather than relying on a restrictive website builder, the new site uses a custom Next.js architecture that allows each service, location, and supporting content page to be intentionally structured and optimized.

The website also connects visitors with White Dove Cleaning’s Housecall Pro booking flow, creating a clearer path from organic search traffic to scheduling a service.

## Key Features

- Custom responsive website design
- SEO-focused page and content architecture
- Dedicated service and location pages
- Page-specific metadata and canonical URLs
- Structured data using JSON-LD
- Internal linking between related services and content
- Optimized image and content delivery
- Reusable React components
- Housecall Pro scheduling integration
- Mobile-friendly navigation and layouts
- Deployment through Vercel

## SEO Strategy

SEO was treated as part of the website’s foundation rather than something added after development.

Optimization includes:

- Search-focused URL structure
- Unique page titles and meta descriptions
- Localized service content
- Semantic heading structure
- Canonical URL implementation
- Open Graph metadata
- Structured data markup
- Search-friendly service architecture
- Supporting informational and blog content
- Strategic internal linking
- Clean, lightweight front-end code

The site is structured to support continued organic growth as additional service pages, location pages, and educational content are published.

## Housecall Pro Integration

The website directs prospective customers into the client’s Housecall Pro workflow for scheduling and lead management.

This allows the custom marketing site to focus on search acquisition and conversion while Housecall Pro handles the operational booking process.
